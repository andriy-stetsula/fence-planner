# Fence Planner — Map Drawing Engine

Реалізація механіки малювання паркану поверх карти за ТЗ
"Fence Planner. Технічне завдання. Механіка малювання та взаємодії поверх карти" (v1.0, 03.08.2026).

> **Карта:** ТЗ описує механіку в термінах Google Maps (GEN-001, GEN-008 та ін.).
> У цій версії як шар карти використано **Leaflet + OpenStreetMap** — безкоштовно,
> без API-ключа і без білінгу. Уся механіка малювання (state machine, snap, розміри,
> undo/redo) не залежить від конкретного провайдера карти: geo↔screen конвертація
> винесена в окремий модуль `src/geo.js`, а рендер — у `src/overlay.js`. Щоб перейти
> на Google Maps API, достатньо замінити ці два файли й ініціалізацію карти в
> `src/main.js` — решта коду (`draw.js`, `state.js`, `model.js`, `history.js`,
> `keyboard.js`) залишається без змін.
>
> Файл референс-макета `Fence_Planner_Desktop_Mockup_V44.html` не був наданий разом
> із завданням. Візуальний стиль тут — мінімальний і зроблений на основі текстових
> вимог ТЗ (розділи 5, 9.2, 19).

## Структура проєкту

```
fence-planner/
├── index.html            # каркас сторінки, підключення Leaflet, popover-панелі
├── style.css              # мінімальний UI (панель інструментів, курсори, popover)
├── src/
│   ├── model.js             # модель даних: Run/Point/Joint/Gate/Post (Додаток A ТЗ)
│   ├── geo.js                # конвертація screen <-> map координат (GEN-008), Leaflet-шар
│   ├── state.js               # State machine редактора (розділ 4 ТЗ)
│   ├── history.js              # Undo/Redo (розділ 21 ТЗ)
│   ├── draw.js                  # малювання прогону + live dimension (розділ 6, 7 ТЗ)
│   ├── snap.js                   # прилипання/з'єднання/T-стик/замкнені контури (розділ 9, 11)
│   ├── joint.js                    # кути, 90°, точний градус (розділ 10)
│   ├── gap.js                       # Fence gap — реальний розрив (розділ 15)
│   ├── gate.js                       # розпашні ворота/хвіртки (розділ 13)
│   ├── slidingGate.js                 # розсувні ворота (розділ 14)
│   ├── posts.js                        # стовпи: END/CORNER/LINE/Additional (розділ 16)
│   ├── select.js                        # вибір, drag, переміщення, delete (розділ 8, 12)
│   ├── overlay.js                        # SVG-рендер, синхронізований з Leaflet map events
│   ├── keyboard.js                        # гарячі клавіші, KeyboardEvent.code (розділ 20, KEY-001)
│   └── main.js                             # точка входу, збирає все разом, popover-логіка
└── README.md
```

## Що вже реалізовано

- [x] SVG-шар синхронізований з картою (Leaflet `move`/`zoom` events, GEN-008 —
      прив'язка в пікселях екрану, дані зберігаються в геокоординатах)
- [x] State machine редактора: `select`, `draw`, `drawSlidingGate`, `placeObject`,
      `dragging`, `editNumber` (розділ 4). Під час взаємодії з елементом редактора
      панорамування карти вимикається (`map.dragging.disable()`), щоб клік не робив
      одночасно кілька речей (PTR-003).
- [x] Малювання прогону по кліках з живим розміром від першої ж точки (DRW-001,
      DRW-002), округлення кроком 0.1 м як налаштування (DRW-003), захист від
      нульового сегмента (DRW-004), Finish run / Enter у фіксованому куті (DRW-005).
- [x] Точна довжина сегмента (розділ 7.3): popover з полем Length, Enter/Esc,
      коректна поведінка коли один або обидва кінці зафіксовані стиком.
- [x] Вибір і переміщення (розділ 8): клік по лінії/вузлу/об'єкту, drag прогону
      (MOV-001), Delete для вузла/прогону/об'єкта з коректним зняттям посилань (8.1).
- [x] Прилипання і з'єднання (розділ 9): endpoint-to-endpoint, endpoint-to-node,
      **endpoint-to-segment (T-стик, SNP-004 — вставляє реальну точку в цільовий
      прогін)**, гістерезис attach/detach (9.4), **блокування resnap одразу після
      роз'єднання (9.3)**, стабільний пріоритет цілей (endpoint/loop → node → segment).
- [x] Кути, 90° і точний градус (розділ 10, JNT-001..006), працює і для кутів
      відкритого прогону, і для кутів замкненого контуру.
- [x] **Замкнені контури (розділ 11, LOOP-001..004)**: автозамикання при підведенні
      останнього вільного кінця до першого (без дублюючої точки), відкриття контуру
      через кнопку замка/клавішу L з тим самим 9.3-гістерезисом.
- [x] Розпашні ворота і хвіртки (розділ 13): на лінії й standalone, стрілки
      hinge/swing, сильне магнітне прилипання без замка (GAT-003/004).
- [x] Розсувні ворота (розділ 14): малювання по двох точках або з точною
      шириною, керування напрямком відкату (SLD-001..004).
- [x] Fence gap — реальний розрив прогону навколо перешкоди (розділ 15).
- [x] Стовпи (розділ 16): END/CORNER (вузли), LINE (авто, не перетягуються,
      PST-001), Additional post з прив'язкою до лінії/стійки воріт, Show/Hide (PST-003).
- [x] Undo/Redo (один pointerdown→pointerup = один крок історії, HIS-001, HIS-002).
- [x] Гарячі клавіші через `KeyboardEvent.code`, працюють у кириличній розкладці
      (KEY-001), не спрацьовують коли фокус в input (KEY-002).

## Що ще НЕ реалізовано

- Переміщення пов'язаних груп прогонів і прикріплених об'єктів разом (MOV-002/003) —
  зараз рухається лише один вибраний прогін (MOV-001)
- Автоматичне рознесення готових розмірів і leader для короткого сегмента (DIM-002/003)
- Об'єкти ділянки: будинок/дерево/басейн/арбор/конверт/parcel pillar (розділ 17)
- Raked / Step-down мітки у вигляді зверху (розділ 18)
- Duplicate (Ctrl+D)
- Magnetic snap воріт/пошти/арбора до довільної лінії під час drag (розділ 17.2/17.3
  описують це для об'єктів; зараз є лише для ворот, поставлених інструментом Swing gates)

## Запуск

Ключ не потрібен. Просто підніми будь-який статичний сервер у корені проєкту:

```bash
npx serve .
```

Відкрий у браузері адресу, яку покаже термінал (типу `http://localhost:3000`),
обери інструмент "Draw a fence line" і клікай по карті.

## Наступний крок

Переміщення пов'язаних груп (розділ 12, MOV-002/003) — коли рухаєш прогін,
з'єднаний closed-стиками з іншими прогонами, вся зв'язана група і прикріплені
об'єкти (ворота, пошта, additional posts) повинні переміщуватись разом.
